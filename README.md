# growth-mind
擴容｜職場裡的溫柔革命
為什麼我想整理成「擴容」

擴容，不是要你假裝沒事，也不是要你把痛苦合理化。

擴容，是把那些曾經讓你難受、失望、委屈、跌倒的經驗，一點一點消化，最後轉化成更深的理解、更穩的情緒、更大的格局，還有更能承接人生起伏的力量。

這本書，不是要你變成「不會痛」的人。而是陪你練習：在痛的時候，不再只會撐硬，而是多一點看見自己、理解自己、放過自己的能力。

這些年，走過幾家企業、穿梭過許多廠房、開過無數次的會議，我看見一個愈來愈明顯的現象：

我們這個時代的工作者，擁有前所未有的工具與資訊，卻也承受著前所未有的「內在緊繃」。

我們學會了敏捷開發、數據分析、專案管理，卻很少有人教我們：當自己明明已經盡力了，卻仍覺得不夠好的時候，該如何安放那份挫敗。

有人在升遷名單上摔了一跤，有人在病床旁打開筆電，有人一邊應付家庭壓力一邊扛著公司業績。表面上大家都還在運轉，心裡卻早已撐得滿滿的。

我常在課後、走廊、電梯旁，聽見那些壓低音量說出口的心事：

「石頭哥，我好像一個快要滿出來的杯子，但還是一直有人往裡面倒水。」

「我也知道不該這麼在意，但就是放不下。」

「我不是不想改變，只是我真的好累。」

那一刻，我總會想起紀伯倫說的話：「悲傷在你內心刻得越深，你能承載的快樂就越多。」

如果有一個詞，既能承認現實的殘酷，又仍然相信人能在裂縫中長出韌性——我想，那個詞就是「擴容」。

擴容，不是要你變得無堅不摧，也不是要你否認那些曾經讓你痛到睡不著的夜晚。

擴容，是讓你的內在容器，慢慢長得更柔軟、更寬闊。寬到可以容納不確定性、暫時的失敗、別人的誤解，甚至是你對自己的失望。

這本書的 48 篇文字，構成了一張向外推演的「同心圓」地圖：

從最內層的情緒擴容、認知擴容，一路走到行動、關係、團隊、策略、時間，最後回到生命擴容——陪你從核心的內在修練，走向外部世界的博弈與整合。

你會看見，原來那些以為撐不過去的時刻，有一天都可能變成你看待別人痛苦時的溫柔；原來那些以為是錯誤的選擇，也可能在未來某個節點，變成你獨一無二的底氣。

人生的痛，不是為了折磨你，而是慢慢幫你「擴容」。

當你翻開這 8 個維度的 48 篇故事，我希望它不只是一組職涯建議，而是一雙在深夜裡遞給你的溫暖手掌。

加油囉，我的朋友。我們書裡見。
